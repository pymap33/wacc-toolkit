WACC Toolkit

One WACC per business segment, plus a capital-weighted sum-of-parts aggregate — computed entirely in your browser via Pyodide. No data leaves this page. For a conglomerate with genuinely different-risk segments — see the hub page if that's not your case.

Consolidated (company-level) inputs

Every segment defaults to these values except its own unlevered beta and capital weight — override a segment's tax rate, cost of debt, or capital structure below only if it genuinely has its own disclosed structure (e.g. a ring-fenced project-finance subsidiary). This calculator only exposes the typical case (per-segment beta + weight); use the Python library directly for per-segment overrides.
